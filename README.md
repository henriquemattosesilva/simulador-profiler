# Simulador Profiler

Simulador de estudo que mostra como a marcação de adjetivos poderia alterar os percentuais de Executor, Comunicador, Planejador e Analista.

Página: https://henriquemattosesilva.github.io/simulador-profiler/

Projeto independente, sem vínculo com a Sólides. Não é o teste oficial e não gera resultado válido. Os pesos são estimados, porque a chave oficial não é pública.

As marcas ficam só no navegador de quem usa.
